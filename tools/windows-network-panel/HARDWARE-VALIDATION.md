# Windows 实机验证

环境检查不等于功能实测，编译通过不等于设备兼容。按操作系统、系统原生架构、客户端架构分别填写，不把 x64 上运行 x86 计为原生 x86 实测，也不把 ARM64 上的模拟运行计为原生 ARM64 实测。

## 准备与只读检查

使用完整解压、架构匹配的 Windows 发布包。在 Windows PowerShell 5.1 中运行：

```powershell
powershell.exe -NoProfile -File .\tools\windows-network-panel\Get-ValidationEnvironment.ps1 -ClientPath '.\ESurfingClient-版本-windows-架构.exe'
```

脚本只输出系统版本、系统架构、PowerShell 位数和启动器路径检查结果，不启动认证、不监听端口、不读取账号配置或热点凭据、不修改网络。需要保存时用 `| Out-File -Encoding utf8 environment.json`；文件保存到自己选定的验证目录。

若脚本被执行策略阻止，记录阻止信息，不要求关闭系统安全策略。无设备或未执行的项目填写“待实测”；不支持热点的网卡记录“不支持”并确认网速、认证仍可用。

## 手动验收步骤

1. 记录发布包版本、来源、客户端架构、设备系统构建号及原生架构。先确认校园网正常，保留当前可用版本和配置备份，避免启动第二个认证客户端。
2. 执行上方检查。`launcherCheck` 应为 `Passed`；检查失败先处理包布局或 PowerShell 环境，不能据此判定热点不可用。
3. 在允许测试的时段，用包内启动器启动辅助采集；确认首页顺序为连接状态、实时网速、热点、当前账号、程序信息。检查 `127.0.0.1` 和 `localhost`，并记录实际 Web/桥接端口。
4. 正常下载或浏览，确认对应网卡速度变化；辅助采集停止或数据过期后，速度显示失效提示，热点操作禁用。恢复采集后可恢复显示。只停止辅助采集，不停止认证客户端。
5. 记录原有热点状态。手动开启热点，手机连接后关闭移动数据并打开网页；同时确认电脑校园网正常。手动关闭热点后，确认电脑仍可联网，最后恢复测试前状态。
6. 关闭网页、退出辅助程序，确认不自动切换热点或中断校园网。权限不足或端口冲突时记录提示；不得为通过验证自动提权、修改防火墙或 URL ACL。

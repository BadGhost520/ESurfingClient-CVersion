关于本程序

        

          
ESurfing 客户端是一个跨平台的电信校园网认证客户端,
            本页面是它的 Web 控制面板

          
支持 Windows / Linux / Android / macOS / OpenWrt

          

            项目地址:
            GitHub
          

          
使用提示: 修改配置后点击"保存"; 点"保存并应用"会重启程序
            (多进程模式下只重启认证进程), 新配置在启动时读取。日志目录、Web 端口与是否允许
            外部访问同样在重启后生效。
